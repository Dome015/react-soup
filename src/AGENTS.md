# Source map

`shared/` contains the sole CSS token and component stylesheets and any framework-neutral code. `react/` and `vanilla/` are independently vendorable implementations, each with components, stories, examples, and local agent guides. React exports its public API from `react/index.ts`; vanilla has prebuilt browser JavaScript in `vanilla/dist/`. Always vendor `shared/` with either implementation. Read that implementation's `AGENTS.md` for the complete component inventory before building a screen. Keep the public components and their visual, behavioral, and accessibility states in parity. Story and example code teaches usage and is not a runtime requirement. No component may import Storybook or example code.
