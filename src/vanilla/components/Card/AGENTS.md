# Card: vanilla HTML contract

## Native pattern

```html
<article class="soup-card"><h2>Projects</h2><p>12 active</p></article>
```

## Usage and accessibility

Use article for self-contained content, section for a named section, or div for a neutral grouping. Keep headings at the correct document level.

## Script requirement

None.

## Reference

Inspect `../../stories/Components/Card/Basic.html` and all sibling story states. Compare them with `src/react/stories/Card.stories.tsx` in light, dark, and auto themes. Styling and every aesthetic value come from `src/shared/styles`; do not add component-local CSS values.
