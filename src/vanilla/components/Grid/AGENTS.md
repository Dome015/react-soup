# Grid: vanilla HTML contract

## Native pattern

```html
<div class="soup-grid soup-gap--md">…</div>
```

## Usage and accessibility

Use the shared sm/md/lg gap class. The CSS grid adapts to available width; do not add one-off gaps in examples.

## Script requirement

None.

## Reference

Inspect `../../stories/Components/Grid/Basic.html` and all sibling story states. Compare them with `src/react/stories/Grid.stories.tsx` in light, dark, and auto themes. Styling and every aesthetic value come from `src/shared/styles`; do not add component-local CSS values.
