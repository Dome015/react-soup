# Stack: vanilla HTML contract

## Native pattern

```html
<div class="soup-stack soup-gap--md">…</div>
```

## Usage and accessibility

Use sm/md/lg shared gaps for vertical composition; prefer this to one-off margins.

## Script requirement

None.

## Reference

Inspect `../../stories/Components/Stack/Basic.html` and all sibling story states. Compare them with `src/react/stories/Stack.stories.tsx` in light, dark, and auto themes. Styling and every aesthetic value come from `src/shared/styles`; do not add component-local CSS values.
