# Inline: vanilla HTML contract

## Native pattern

```html
<div class="soup-inline soup-gap--md soup-align--center soup-justify--start">…</div>
```

## Usage and accessibility

Use shared gap, align, and justify modifier classes; between separates groups. Let content wrap naturally on narrow widths.

## Script requirement

None.

Inspect `../../stories/Components/Inline/Basic.html` and all sibling story states. Compare them with `src/react/stories/Inline.stories.tsx` in light, dark, and auto themes. Styling and every aesthetic value come from `src/shared/styles`; do not add component-local CSS values.
