# Container: vanilla HTML contract

## Native pattern

```html
<div class="soup-container">…page content…</div>
```

## Usage and accessibility

Use for readable maximum page width and horizontal gutters. Compose Stack, Inline, and Grid within it before writing page layout CSS.

## Script requirement

None.

## Reference

Inspect `../../stories/Components/Container/Basic.html` and all sibling story states. Compare them with `src/react/stories/Container.stories.tsx` in light, dark, and auto themes. Styling and every aesthetic value come from `src/shared/styles`; do not add component-local CSS values.
