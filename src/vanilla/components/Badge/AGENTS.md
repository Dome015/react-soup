# Badge: vanilla HTML contract

## Native pattern

```html
<span class="soup-badge soup-tone--success">Active</span>
```

## Usage and accessibility

Use neutral for ordinary metadata, success for positive state, warning for caution, danger for failure, and info for information. Keep the state in text as well as color.

## Script requirement

None.

## Reference

Inspect `../../stories/Components/Badge/Basic.html` and all sibling story states. Compare them with `src/react/stories/Badge.stories.tsx` in light, dark, and auto themes. Styling and every aesthetic value come from `src/shared/styles`; do not add component-local CSS values.
