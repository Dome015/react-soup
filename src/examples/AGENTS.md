# Example pages and patterns

Every child directory contains a React example and its own `AGENTS.md`. These examples demonstrate composition and appropriate placement of components. They are reference code for agents building a host app and are not runtime imports of the library. Storybook exposes them in `Examples` stories. Use the standard layout primitives and tokens; do not duplicate component styles or introduce literal CSS values in examples.

Examples cover settings, authentication, CRUD listing, search with filters, empty state, confirmation, destructive action, page header, sidebar navigation, table toolbar, pagination, profile, and dashboard. Start from the closest example when building a new screen.
Use a direct heading and concise supporting copy. Do not use eyebrow labels above headings or uppercase accent labels on statistics.
